# Contributing to Awesome AI Tools

Thanks for helping make this list better!

## Guidelines

1. **Free tier / open source only** — no paid-only tools
2. **Include a code snippet** — every entry must have a working example
3. **Keep it organized** — add to the right category file
4. **One entry per PR** — keeps reviews clean

## Entry Template

```markdown
### Tool Name

[![GitHub Stars](https://img.shields.io/github/stars/user/repo?style=flat-square)](https://github.com/user/repo)

**Description:** One-line description of what this does

**Free tier:** What's available without paying

**Docs:** [link](https://docs.example.com)

**Snippet:**
```language
// working code example
```
```

## Style Guide

- Use `###` for tool names (third-level heading)
- Sort alphabetically within each category
- Use the badge format shown above for GitHub projects
- Keep descriptions under 15 words
- Code snippets must be syntactically valid
